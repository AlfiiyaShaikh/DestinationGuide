# 🗺️ Travel Destination Guide

**Travel Destination Guide** is a Java desktop application built using **Swing** and **JDBC**. It allows users to view, add, edit, and delete travel destinations. Only the user who added a destination can modify or delete it, ensuring secure access with session management.

## ✨ Features

- User Registration & Login
- Add, View, Edit, and Delete Travel Destinations
- Only the creator can edit or delete their destinations
- Secure Session Management
- Simple, clean GUI using Java Swing
- Database connectivity using JDBC
